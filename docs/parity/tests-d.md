Audit of the 22 C++ test files (`252` test functions) in `target/cpp-ref/tests/` assigned to Order `T1-d` against the Rust workspace in `crates/`. Read-only audit: no Rust or C++ code was edited, compiled, or executed.

Status legend:
- `PORTED` — A Rust test covers the same behaviour and key assertions as the C++ test.
- `PARTIAL` — A Rust test exercises part of the logic, wording, or math, while omitting other assertions (for instance UI interactions, error paths, multi-step state machines, or coordinate/layer integration).
- `MISSING` — No Rust test verifies this behaviour (noted with `NOT BUILT` where the Rust production feature itself does not exist, or naming the untested Rust symbol where code already exists without tests).
- `BLOCKED` — Depends on an unported runtime subsystem (`WB1` embedded WebView / `QWebEngineView`, `R3`/`W50` PDF export & `QgsLayout` composer / legend engine).
