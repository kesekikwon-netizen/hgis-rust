# Strata 최종 디자인 설계도 (Design Specification)

> 원본: `Strata 디자인 개선안 2차.html`(9 보드) + `Strata UI·UX 개선안.html`(6 보드)
> **실측 보완**: `build\Release\ka-hgis.exe` (2026-10-24 빌드) · 창 1600×900 · 배율 150%
> 이 문서는 두 제안서의 **15개 아트보드 전체**와 **C++ 앱 실측 21개 화면**을 하나로 합친 최종 설계도다.
> 중복은 합치고, 한 번도 빠뜨리지 않았다.
> 원본의 「제안」 표시가 붙은 항목은 현재 앱에 없는 신규 제안이다.

## 2. 켜짐의 세 모습 (7장 02)

리본의 크기 · 순서 · 글자 · 그림은 **앱 그대로** 두고 색 칸만 바뀐다.
**넓게(굵게) 하지 않는다.** 굵기는 리본 글자만 앱 그대로.

| 상태 | 모습 |
|---|---|
| 기본 | 타일 `#E4EAED`, 그림 `#2B4858` |
| 올려놓음 | 타일 `#D9E2E7` |
| 누름 | 타일 `#E8E6DC` |
| 손에 듦(그리기) | 먹색 면 + 흰 그림 |
| 켜서 보임(지형 등) | 타일 `#E0ECF8`, 테 `#1A68B0`, 그림 `#105088` |
| 못 씀 | 타일 `#EEF1F3`, 그림 45% |
| 저장 안 됨 | 「저장」 타일 + 흙색 점 6 px |
| 초점 | 먹색 2 px 테 |

타일 규격: **50 × 50**, 반지름 = 타일 × 0.25, 그림 상자 = 타일 × 18/32, 테 = 타일 × 2/32.

## 5. 부품 (7장 05)

### 5.1 단추 — 네 가지 × 다섯 상태
| 종류 | 예 | 높이 |
|---|---|---|
| 주(흙색 면) | 저장 · 이어서 열기 | 32 · 40 |
| 보조 | 조사 열기 · 새 조사 | 24 · 32 · 40 |
| 조용한 | 위치 보기 · 설정 | 24 |
| 위험 | 저장 안 함 | 24 |

**주 단추는 한 화면에 하나.**

### 5.2 상태별
기본 / 올려놓음 / 누름 / 못 씀 / 초점 — 각각 위 2장의 색 규칙을 따른다.

### 5.3 풍선말
먹색 면, 단축키는 모노. 예: `되돌리기 Ctrl+Z`.

### 5.4 입력
| 부품 | 규칙 |
|---|---|
| 숫자 · 단위 | `mm` 같은 단위가 뒤에 붙음 |
| 날짜 | 올림/내림 |
| 고르기 | 범례 조각이 앞에 — 청동기 / 원삼국 / 조선 |
| 조절 막대 | 틀림은 붉은 테 + 아래에 까닭 |
| 이어 붙인 고르기 | 고른 칸은 먹색 테 — A4 / A3 / 직접 입력 |
| 색 고르기 | 앱의 여덟 색 · 고른 색은 테와 이름 |
| 체크 · 고르기 · 켜짐 | 먹색 — `면적(㎡) 함께 ���시`, `채우기 없음 (선만)` |

틀린 입력 문구 예: `조사명에는 \ / : * ? " < > | 와 제어 문자를 쓸 수 없습니다.`

### 5.5 지도 위 조각
흰 면, 1 px 테, 반지름 8, 그림자.
축척자 견본: `도북 0 10 20 m` — **도북 표시는 제안**.

### 5.6 투명도 카드
`유구 (면)` 이름 + `투명도 20%` + 밝기 줄(`—`, 「밝기는 그림 레이어에서만 조절합니다」).

### 5.7 시대 띠 · 종류 무늬
시대 색(앱의 색 띠 그대로, 고른 시대에 먹색 틀): 구석기 · 신선기 · 청동기 · 초기철기 · 원삼국 · 삼국 · 통일신라 · 고려 · 조선 · 미정 — **시대 띠는 제안**.
종류 무늬 8가지: 주거지 · 수혈 · 구 · 도랑 · 분묘 …

## 6. 상태 표시 (7장 06)

**알약(pill)은 없다. 표시와 글자로만 말한다.**

| 상태 | 모습 |
|---|---|
| 저장됨 | 보통 · 회색 글자만 |
| 저장 안 됨 | 손이 필요함 · 흙색 점 + 글자 |
| 변경됨 · 아직 저장 안 됨 | 오른쪽 판의 상태 줄 |
| 주의 3 | 주의 · 세모 + 먹색 글자 |
| 오류 1 | 제출을 막음 · 붉은 표시 + 글자 |
| 원본 없음 | 파일을 찾지 못함 |
| 오류·주의 없음 | 결과를 알릴 때만 초록 체크 |
| 다음 | 「다음」「추천」 만 흙색 글자 |

## 8. 화면 1 — 지도 (1920×1040)

### 8.1 구성 (위 → 아래)
1. **제목 표시줄** — `광령리1 * - Strata` (`*` = 저장 안 됨)
2. **리본 7묶음**
   - 조사: 새 조사 · 열기 · 저장 · 다른 이름
   - 기록: 선택 · 측거 · 그리기 · 시굴격자 · 버퍼
   - 자료 받기: 지적 · 수치지형 · 유산
   - 배경 지도: 지형 · DEM · 등고선 · 토양 · 고지형 · 지질 · 수계 · 옛 지도
   - 정합: 정합

   - **DEM은 「배경 지도」가 아니라 「자료 받기」다** (원본 5장·7장 공통 표기)
