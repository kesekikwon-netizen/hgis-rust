1. **도면 캔버스 좌상단 정적 사각형(`gui_tab_drawing.rs:331-349`)을 실제 `self.render_layer_opacity_rail(ui, rect)` 호출로 교체 (`KaDrawingStudio.cpp:1190-1225`)**:
   - 현재 `gui_tab_drawing.rs:331-349`는 `"투명도·밝기: 조절할 레이어를 고르세요"`라는 고정 텍스트 상자만 그려서 레이어를 선택해도 슬라이더가 나오지 않는다.
