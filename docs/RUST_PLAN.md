## 1. 목표

1. **현장 한 바퀴**: Rust 판에서 다음 일을 처음부터 끝까지 할 수 있고, 결과물이 C++ 판과 같다.
   새 조사 → 조사구역·유구·유물·단면·기준점 기록 → 검수 → 제출 꾸러미(EPSG:5179 SHP + MANIFEST) + 조사도면 PDF.
2. 그다음 **세부 일치**: C++ 창 65개, 우클릭 메뉴, 리본, 글자·여백까지 같다.
3. **판정 기준**: C++ 앱이 실제로 만든 파일·화면과 맞대 본다. 시험 통과나 「단추가 있음」은 완성이 아니다.
4. **화면 기준**: 지금의 C++ 앱(기본 모양)이다. `docs/DESIGN_SPEC_FINAL.md` 의 「제안」 항목은 세부 일치가 끝난 뒤에 따로 정한다.

## 2. 설계 — 앱의 구조

```
화면  strata-app (egui) ── 리본 · 지도 · 레이어 패널 · 창 · 오른쪽 카드
  │
  ├─ 조사 파일  strata-storage ── 조사 파일(GPKG, C++ 과 같은 형식)
  │                               ⇄ 편집 중인 도형(저장 전 음수 번호)
  │                               ⇄ 「저장」 = 사본에 쓰고 확인한 뒤 바꿔 끼움
  │
  ├─ 엔진      strata-engine ──── 지금: PROJ(좌표 변환) · GEOS(도형 고치기)
  │                               다음: GDAL(SHP · GeoTIFF · DXF 읽고 쓰기)
  │                               11/26 뒤: RustGIS(지도 그리기 · 타일 · PDF)
  │
  ├─ 검수·제출  strata-check-export ── 검수 27가지 → 제출 꾸러미
  ├─ 자료 받기  strata-net ──────── VWorld 지도·지적도, 국가유산 인트라넷, 수치지형도
  └─ 계정      strata-secrets ──── C++ 과 같은 저장소(ini · Windows 암호화)
```

지키는 원칙:
- 좌표·도형·GIS 파일 계산은 **엔진 크레이트 하나**에서만 한다. 손으로 짠 계산은 엔진으로 옮긴다.
  지금 남은 손 계산 11개 파일은 E1 에서 옮긴다.
- 화면·문구·검수 규칙·도면 양식은 **C++ Strata 그대로** 둔다. 엔진의 기본값이 Strata 규칙을 바꾸게 하지 않는다.
- **가짜 금지**: 지어낸 자료, 일하지 않고 「했습니다」만 띄우는 단추, 빈 파일을 만들지 않는다.
  아직 옮기지 않은 기능은 흐리게 두고 「아직 Rust 판에서 연결하지 않았습니다 (지시 ○○)」라고 알린다.

## 5. 일하는 방식

- 지시자(시니어 세션): 계획, 지시, 검수. 소스는 고치지 않는다.
- 작업자 세션: 구현, 시험, 커밋, 올리기.
- 지시 하나 = 작은 기능 하나. C++ 근거(파일:줄)와 기대값을 주고, 시험을 먼저 쓰게 한다.
  검수는 C++ 실물과 맞대 본 뒤 통과시킨다.
- 작업 규칙 전문은 `docs/senior/rules_v1.yaml`, 세션끼리 주고받는 형식은 `docs/senior/PROTO_V1.txt` 에 있다.
