## 1. Home screen (`홈`)

- **C++ title (verbatim) & where built**: No standalone window title; embedded `KaStartPage` widget inside `MainWindow` `m_viewTabs` tab `"홈"` (`MainWindow.cpp:1070-1071`, `KaStartPage.cpp:80-203`).
- **How user opens it**:
  - **C++**: Shown on startup as tab index 0 (`MainWindow.cpp:1070-1071`); clicking `"홈"` tab triggers `currentChanged` -> `m_startPage->reload()` (`MainWindow.cpp:1081-1086`).
  - **Rust**: Shown on startup (`MainTab::Home`); clicking `"홈"` tab in ribbon tab bar sets `self.active_tab = MainTab::Home` (`gui_ribbon_tabbar.rs:42,74-76`).
- **Modality**: Modeless embedded page on both sides (`QWidget` inside `QTabWidget` in C++, `CentralPanel` / `ScrollArea` in Rust).
- **Size rules**:
  - **C++**: Hero compact/tall thresholds `kHeroCompact = 184`, `kHeroTall = 236`, `kCompactWindowHeight = 820`, `kRightNarrow = 340`, `kRightWide = 400`, `kNarrowWindowWidth = 1500` (`KaStartPage.cpp:33-39`); `m_filter` `setFixedWidth(260)` (`KaHomeRecentCard.cpp:64`); `KaPeriodBand` not on home, recent row height `kRowHeight`.
  - **Rust**: Hero block + two-column recent/guide (`recent_w` up to 77% bounded by `GUIDE_MIN_W = 300.0`, `gui_tab_home_recent.rs:18-23`); recent filter `desired_width(260.0)` (`gui_tab_home_recent.rs:37`).
- **Rust counterpart**: `crates/strata-app/src/gui_tab_home_hero.rs`, `gui_tab_home_recent.rs`, `gui_tab_home_recent_box.rs`, `gui_tab_home_status.rs`, `home_connection_model.rs`, `crates/strata-secrets/src/account_status.rs`.

### Keyboard and closing behaviour
- **C++**: On `KaStartPage::showEvent`, if the continue block is visible, keyboard focus is queued onto `m_resume` (`m_resume->setFocus(Qt::OtherFocusReason)`, `KaStartPage.cpp:316`). Tab order traverses `새 조사`, `조사 열기`, `m_resume`, `m_filter`, `m_table`, `m_internetButton`, and the 5 `설정` buttons. Embedded tab widget (not closable).
- **Rust**: Embedded tab inside `CentralPanel`; standard egui Tab focus order. `recent_filter` (`TextEdit::singleline`) has no clear button (`gui_tab_home_recent.rs:35-38`). Not closable.
