### DEM 방향 (2026-11-11 사용자 지시 두 줄)
- 「국토지리원에서 DEM을 받아야한다.」 「수치지형도를 받을때 쓰는 라인으로 DEM만 받아와야한다」
- 뜻: 국토정보플랫폼(map.ngii.go.kr)에서 수치지형도를 받는 것과 **같은 통로**(로그인 → 신청 → 내려받기)로 DEM 자료를 받는다. 해외 공개 자료(Copernicus)를 받는 지금의 길도, 등고선으로 DEM 을 직접 만드는 길도 아니다(Claude 가 처음에 등고선 합성으로 잘못 읽었다가 바로잡음).
- 그래서 순서는: (1) 수치지형도 통로(앱 안 웹 화면 + C++ 의 자동화 스크립트 `data/providers/ngii-topographic.js`)를 Rust 에 만든다 → (2) 같은 통로에서 DEM 상품을 고르는 요청을 실제 사이트에서 확인해 붙인다 → (3) 받은 DEM 을 지도에 색·음영으로 그린다(읽기 부품은 `strata-paleo::dem_tiff_read`).
- 미확인: 국토정보플랫폼에서 DEM 을 고를 때 나가는 요청(수치지형도는 `suchiQuery.do` type=0 scale=25000)과 받는 파일 형식. 실제 사이트에서 확인해야 한다.
- 확인(2026-11-11, 실제 사이트·로그인 없이): 국토정보플랫폼 지도 화면에 「공개DEM」 구획이 따로 있다. 검색은 `POST /ms/map/demQuery.do`(minx·miny·maxx·maxy·wkt, EPSG:5179; 연도 목록은 `demYearsQuery.do`), 결과는 1:50,000 도엽 단위(예: 견본 위치 → 도엽 36705 「전의」, 2014·2021~2025년). 내려받기는 수치지형도와 같은 함수 `downloadMapData('4','online',[{types:'index',years,nums,names}])` → 로그인 확인(`/mn/loginCheck.do`) → 신청 양식(`/pd/shbtManage/dowloadRequestForm.do`) → 내려받기. 즉 사용자 말대로 「수치지형도를 받을 때 쓰는 라인」 그대로다.
- 미확인: 로그인 뒤의 DEM 신청 양식 항목과 받는 파일 형식(로그인해야 볼 수 있다).
- 진행(2026-11-11 저녁): 웹 화면 도우미 `ka-hgis-web`(WebView2)와 자동 진행 단계를 옮겨, 저장된 계정으로 실제 로그인해 **수치지형도(도엽 367051 「광덕」)와 공개DEM(도엽 36705 「전의」 2025년) 둘 다 공식 신청서가 열리는 데까지** 확인했다(약 12초, 창 감춤, 제출 안 함). DEM 신청서에는 수치지형도에 없는 항목 `onBasis` 가 하나 더 있다.
- 남은 것(사용자 답이 필요): 신청서의 「다운로드」를 누르면 사용자 이름으로 실제 신청이 접수된다. 생년월일은 C++ 도 저장하지 않고 실행 때마다 입력받는다. 그래서 제출·파일 받기 단계는 사용자가 값을 주고 허락한 뒤에 실제로 확인한다.
- 보안: 스크립트·계정 입력은 https 의 ngii.go.kr 화면에서만(도우미와 화면 안에서 두 번 확인), 이동은 ngii.go.kr 와 정부 통합인증 `sso.anyid.go.kr`(지나가기만)로 제한.
- 사용자 답(2026-11-11): 공개DEM 1장 실제 신청 「신청해서 받아 보기」, 사용목적 문구 「C++ 과 같은 문구」. 사용목적 분류를 묻자 「C++안에 경로가 다있잖아 없나?」 — 확인: C++ 에는 국토정보플랫폼 DEM 경로가 없고(해외 공개자료를 받음), 수치지형도 신청서도 사이트가 바뀌어 C++ 이 고르던 「기타(BAAAC00008)」가 없어졌다(지금 목록: 제작 및 활용 → CAAAC00001~7). 그래서 Claude 가 「교육, 학술, 연구(CAAAC00006)」를 기본값으로 정했다(추측이 아닌 Claude 의 선택, 사용자가 바꿀 수 있음).
- 실제 신청 2회(같은 도엽 36705 「전의」 2025): 1회차 접수 확인됐으나 전송 창이 설치 안내로 넘어가 파일 못 받음 → 설치 없이 받는 설정을 옮김. 2회차 접수됐고 전송 창은 제대로 열렸으나, 응답의 `orderDownList` 가 비어 「지연」으로 판단해 파일 단계로 넘어가지 못함 → 고침. **파일 받기는 아직 확인하지 못했다.** 더 신청하기 전에 사용자에게 묻는다.
