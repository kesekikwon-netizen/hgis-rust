# 진화 목록 — 이 앱은 항상 진화한다

- 사용자 지시 2026-11-14: 「이 앱은 항상 진화해야 한다.」
- 관리: 지시자. 계획서 `docs/RUST_PLAN.md` 7절이 이 문서를 쓰는 방법을 정한다.
- 뜻: C++ 기능을 다 옮겼다고 끝나지 않는다. 「완성」이라고 닫지 않고, 더 나아질 길이 보이면 여기에 적어 두었다가 지시로 만든다.

## 규칙

1. **먼저 되게, 그다음 더 낫게.** 어떤 기능이 C++ 과 같게 실제로 동작하기 전에는 그 기능을 새 방식으로 바꾸지 않는다. 사용자가 일부러 다르게 정한 것(아래 표의 「사용자 결정」)만 예외다.
2. **후보는 근거와 함께 적는다.** 무엇이 지금 불편하거나 위험한지(파일:줄, 화면, 숫자), 바꾸면 현장에서 무엇이 나아지는지, 무엇이 깨질 수 있는지.
3. **후보는 어디서나 온다.** 개발자 보고서의 `evolve` 칸, 조사 문서(기능 대조표·접속 방식·자료 받기 흐름), 검수 중에 본 것, 사용자의 말, 부품의 새 판.
4. **지시로 만들 때는 보통 지시와 같다.** 작은 기능 하나, 정확한 기댓값, 시험 먼저. C++ 과 달라지는 점은 지시서에 「사용자 결정」 또는 이 문서의 항목 번호로 적는다.
5. **항상 몇 개는 돌고 있다.** 옮기는 지시가 밀려 있어도 창 하나쯤은 진화 지시나 그 조사에 쓴다. 옮길 것이 다 끝나면 모든 창이 이 목록으로 일한다.
6. **사용자만 정할 수 있는 것**(화면이 눈에 띄게 달라짐, 사이트 이용 방식, 라이선스)은 지시 전에 한 번 묻는다.
