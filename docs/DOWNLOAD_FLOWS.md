# Strata Site Data Download Flows — C++ Reference vs. Rust App (`DL0`)

This document records, from source evidence only (`target/cpp-ref/src/**` for C++ and `crates/**` for Rust), what the user sees from click to result in every function that fetches data from a remote site, together with the bottom status bar and progress elements in both apps. It contains facts and `file:line` citations only.

## 2. Bottom Status Bar of Both Apps

### 2.1 C++ Bottom Status Bar (`MainWindowChrome.cpp`, `KaStatusBar.cpp`, `KaDrawSketchTools.cpp`, `MainWindow.cpp`)

`MainWindow::setupStatusBarChrome()` (`target/cpp-ref/src/app/MainWindowChrome.cpp:157-193`) constructs `KaStatusBar` (`target/cpp-ref/src/app/KaStatusBar.cpp:42-257`) on `statusBar()` and `KaDrawSketchTools` inserts `toolChip` at permanent index `0` (`target/cpp-ref/src/app/KaDrawSketchTools.cpp:242-254`).

Left to right, the bar displays:

#### Stages (C++ in order)

1. Initial marquee (`0..0`): `QProgressDialog#mapDownloadProgress` opens with `DEM 자료를 내려받는 중입니다. 지도 작업을 계속할 수 있습니다.` (`target/cpp-ref/src/app/MainWindowDownloads.cpp:23-25, 89`).
2. `0% → 20%`: Opening each 1°×1° remote COG `/vsicurl/https://copernicus-dem-30m.s3.amazonaws.com/...` via `GDALOpenEx`; after each tile `feedback->setProgress(20.0 * openedTiles / tileCount)` (`target/cpp-ref/src/core/DemDownloadService.cpp:160-204`). (`startFileDownload` switches the dialog to `setRange(0, 100)` and updates `setValue(...)` via `QgsTask::progressChanged` at `target/cpp-ref/src/app/MainWindowDownloads.cpp:84-88`.)
3. `20% → 25%`: Building in-memory VRT mosaic via `GDALBuildVRT` (`progress.begin = 20.0; progress.span = 5.0`, `target/cpp-ref/src/core/DemDownloadService.cpp:225-231`).
4. `25% → 99%`: Reading pixels over HTTP and writing compressed GeoTIFF via `GDALTranslate` (`progress.begin = 25.0; progress.span = 74.0`, `target/cpp-ref/src/core/DemDownloadService.cpp:267-272`).
5. `99% → 100%`: Closing and reopening `dem.tif` to verify band count, dimensions, geotransform, and positive byte size (`target/cpp-ref/src/core/DemDownloadService.cpp:278-298`).
